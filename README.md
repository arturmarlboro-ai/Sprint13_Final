Веб-приложение на Go для управления задачами с поддержкой повторяющихся событий.

Возможности:

Создание, редактирование и удаление задач
Поиск задач по заголовку и комментарию
Поддержка правил повторения: ежедневно (d), по дням недели (w), по числам месяца (m), ежегодно (y)
Отметка задачи как выполненной — при наличии правила повторения автоматически рассчитывается следующая дата
JWT-авторизация через cookie

Выолнил задания со звёздочкой- поддержка переменных окружения

## API

| POST   | `/api/signin`        | Вход, возвращает JWT-токен 
| GET    | `/api/tasks`         | Список задач (поиск через `?search=`) 
| GET    | `/api/task?id=`      | Получить задачу по ID 
| POST   | `/api/task`          | Создать задачу 
| PUT    | `/api/task`          | Обновить задачу 
| POST   | `/api/task/done?id=` | Отметить задачу выполненной 
| DELETE | `/api/task?id=`      | Удалить задачу 
| GET    | `/api/nextdate`      | Рассчитать следующую дату по правилу повторения
